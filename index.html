📘 Guide

How to get your save off the PlayStation, edit it, and put it back with Save Wizard for PS4 MAX.

Before you start, you need:
  • A Save Wizard for PS4 MAX license and the app on your computer (Windows or Mac). Get it from the official Save Wizard website.
  • A USB stick formatted as exFAT or FAT32.
  • The PS4 version of Saints Row. It still works if you play it on a PS5. Saves from the PS5 version of the game can't be edited.
Part 1: Get your save out

Save the game and close it

Play Saints Row, save, then close the game completely (press the PS button and choose Close Game).

Copy the save to your USB stick

Plug the USB stick into your PlayStation, then:

PS4: Settings → Application Saved Data Management → Saved Data in System Storage → Copy to USB Storage Device → Saints Row → tick your save → Copy.

PS5: Settings → Saved Data and Game/App Settings → Saved Data (PS4) → Console Storage → Copy to USB Drive → Saints Row → tick your save → Copy.

Open Save Wizard on your computer

Plug the USB stick into your computer and open Save Wizard for PS4 MAX. Log in if it asks. After a moment it shows the games it found on the USB stick.

First time only: add your profile. Save Wizard needs to know your PlayStation account so it can sign saves for you. Find the Profiles option in Save Wizard (in settings) and register your profile using a save from your own account on the USB stick. Give it your name.

Get the unlocked file out

  1. Click Saints Row, then click your save.
  2. Click Advanced Mode.
  3. Choose the file SAVEDATA0.DAT.
  4. Click Decrypt (also called Export or Download) and save it somewhere easy, like your Desktop.

Button names can change a little between Save Wizard versions. Look for the one that gets the file out.

Part 2: Edit it with WBWHO

Open it in WBWHO and make a backup

On the 🏠 Start tab, click Open my save file and pick SAVEDATA0.DAT. Then click 🛟 Download a backup copy and keep it safe.

Change what you want

Go to 🎮 Edit. Use ⚡ Max Everything, or change things one at a time.

First time? Start small. Change only your money, put it back, and check the game loads. Then come back and do the rest. If something goes wrong, you'll know exactly what caused it.

Save it

Click 💾 Save at the top. Your browser downloads SAVEDATA0.DAT.

Keep the name exactly SAVEDATA0.DAT. If your computer renamed it (like SAVEDATA0 (1).DAT), rename it back.
Part 3: Put it back

Replace the file with Save Wizard

  1. In Save Wizard, click the same Saints Row save as before.
  2. Click Advanced Mode and choose SAVEDATA0.DAT.
  3. Click Replace (also called Import) and pick the file WBWHO gave you.
  4. If it asks which profile to use, pick your profile. This is called re-signing.
  5. Wait until it says it's done. Save Wizard locks the save again and writes it back to the USB stick.
Don't copy the file straight onto the USB stick. The PlayStation can't read an unlocked file. It must go back through Save Wizard's Replace.

Copy it back to your PlayStation

Make sure Saints Row is closed, plug the USB stick into your PlayStation, then:

PS4: Settings → Application Saved Data Management → Saved Data on USB Storage Device → Copy to System Storage → Saints Row → your save → Copy → Overwrite.

PS5: Settings → Saved Data and Game/App Settings → Saved Data (PS4) → USB Drive → Copy to Console Storage → Saints Row → your save → Copy → Overwrite.

Play! 🎉

Start Saints Row and load that save. Your changes should be there.

Tip: if you use PS Plus cloud saves, the console may offer to download the cloud copy. Say no, or it will replace your edited save.

Help! My save won't load

Go down this list. Most problems are fixed by one of these:

  1. Did it go back through Save Wizard's Replace? Copying the .DAT file straight onto the USB stick never works.
  2. Is the name exactly SAVEDATA0.DAT? No "(1)" or other extra bits.
  3. Did you replace the same save you took out? Different save slots can't be mixed.
  4. Did you pick your own profile when re-signing? A save signed to another account won't load.
  5. Did the cloud overwrite it? Turn off auto-upload/download for Saints Row while testing.
  6. Too much at once? Put your backup back, then try changing only money. If that works, add more a bit at a time.
  7. Big numbers: giving yourself huge XP can confuse the game. WBWHO's ⚡ Max Everything button leaves XP alone for that reason.

Still stuck? Write down exactly what the PlayStation says (for example "The saved data is corrupted") and which steps you did. It helps a lot to figure out what went wrong.

Good to know
🏆 Will this mess up my trophies?

No. Trophies are kept on your PlayStation account, not in the save file, so WBWHO can't remove any you already have.

Unlocking everything might make the game give you trophies for collecting stuff. If you only want trophies you earned yourself, don't unlock everything.

💰 Find a number by yourself (any game)
  1. In the game, look at the number (example: money is 12500).
  2. On 🔎 Find, type 12500 and click Find it!
  3. One spot found? Click ⭐ Make a button. Lots? Change the number in the game, save, and use Load my newer save to narrow it down.
🆚 Missions and other unlocks

Save before doing something (like a mission), then save after. Put both in 🆚 Compare to see exactly what changed, and copy it into any save.

📖 Word list
  • Save file: where the game keeps your progress.
  • Locked / encrypted: scrambled so only the PlayStation can read it.
  • Unlocked / decrypted: unscrambled, so WBWHO can read it.
  • Re-sign: stamping the save with your account so your PlayStation accepts it.
  • Backup: a safe copy of your save, just in case.
  • Spot #: where something is inside the file, like a page number in a book.
